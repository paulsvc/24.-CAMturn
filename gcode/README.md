# Generated & Verified CNC G-Code Samples

This folder contains CNC G-code programs generated by **LatheCAM** and automatically verified by the built-in **G-Code Geometric Verifier & Backplotter (`src/lathecam/post/verifier.py`)**.

---

## Which File Should I Open in NC Viewer (`ncviewer.com`)?

> [!IMPORTANT]
> **For [ncviewer.com](https://ncviewer.com), CAMotics, or generic WebGL G-code viewers, open [`stepped_shaft_ncviewer.nc`](stepped_shaft_ncviewer.nc)!**
>
> Why?
> 1. **1:1 Radial Coordinates (`X = radius`, `I = radius_offset`):** NC Viewer plots `X` and `Z` in 1:1 Cartesian coordinates by default (`center_x = start_x + I`). Using 1:1 radius mode ensures `r_start == r_end` to `< 0.0004 mm` on every `G02`/`G03` arc without needing to toggle hidden viewer settings.
> 2. **Dedicated `G18` Plane Selection & `XZ` Arc Chirality:** Places `G18` on its own line and matches Three.js/WebGL `XZ` plane (`atan2(dZ, dX)`) arc orientation so convex corners and concave fillets never loop 270° backwards.
> 3. **Unrolled Threading & Peck Drilling:** Since NC Viewer does not expand lathe `G76` threading or `G83` peck drilling canned cycles, `stepped_shaft_ncviewer.nc` unrolls all multi-pass thread cuts and peck drilling strokes into explicit `G00`/`G01` moves so the complete operation sequence is visible.

## Automated G-Code Verification (`src/lathecam/post/verifier.py`)

Every generated G-code program is automatically backplotted and checked against 7 geometric invariants:
1. **Arc Endpoint Radius Consistency (`ARC_RADIUS_MISMATCH`):** Verifies $|R_{\text{start}} - R_{\text{end}}| \le 0.005\text{ mm}$ after `.3f` coordinate formatting.
2. **Runaway Arc Filter (`ARC_RUNAWAY_RADIUS`):** Prevents collinear/taper segments from being fitted with huge radius circles.
3. **Arc Sweep & Chirality Check (`ARC_EXCESSIVE_SWEEP`):** Flags any unintended $>185^\circ$ loop caused by inverted `G2`/`G3`.
4. **Orthogonal Rapid Clearance (`RAPID_DIAGONAL_IN_STOCK`):** Ensures `G0` rapid moves use orthogonal box-cycle retracts (radial X out to safe clearance, then axial Z) and never cut diagonally across the stock envelope.
5. **Rapid Part Collision Check (`RAPID_PART_COLLISION`):** Verifies no `G0` rapid move intersects the finished part polygon.
6. **Physical TNRC Insert Gouge Check (`CUT_PART_GOUGE`):** Sweeps the physical tool nose circle along all `G1`/`G2`/`G3` cutting moves and verifies zero part gouging.
7. **Spindle, Feedrate & Redundancy Linter:** Ensures `M3` and `F` are active before cutting and eliminates duplicate consecutive `G0` moves.
