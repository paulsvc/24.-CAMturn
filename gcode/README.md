## Dialect & Machine Setup Notes

### 1. LinuxCNC (`.ngc`)
- **Preamble:** `G18 G21 G40 G49 G80 G90 G95 G7`
- **Tool Changes:** `T<id> M6 G43`
- **Spindle Speed:** Constant Surface Speed `G96 D<max_rpm> S<css> M3` (using LinuxCNC `D` clamp word)
- **Arcs:** `G18` ZX Plane with `I` (incremental X radius offset) and `K` (incremental Z distance offset)

### 2. Fanuc 0i-TF / ISO (`.nc`)
- **Preamble:** `G18 G21 G40 G80 G99`
- **Tool Changes:** 4-digit Fanuc tool call (e.g. `T0101`, `T0202`)
- **Spindle Speed:** Max RPM clamp `G50 S<max_rpm>` followed by CSS `G96 S<css> M03`
- **Canned Cycles:** Standard 2-block Fanuc `G76 P.. Q.. R..` threading and `G83` peck drilling
- **Footer:** Zero reference return `G28 U0.0 W0.0`, `M05`, `M30`
